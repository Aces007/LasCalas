The official web platform and booking portal for **LasCalas Resort & Luxury Estate**, an exclusive sanctuary in Dasol, Pangasinan designed as a serene haven for families and guests seeking elevated leisure.

---

## ⚡ Overview & Key Features

* **High-Performance UI/UX:** Custom responsive interface designed in Figma and developed with React & Tailwind CSS, optimized for mobile touch ergonomics and smooth transitions.
* **Integrated Booking Engine:** Connected with multi-channel reservation systems (OTA sync, direct reservations, and live availability tracking).
* **Automated CI/CD Pipeline:** Built-in GitHub Actions workflow for automated builds, asset optimization, and zero-downtime deployment to DreamHost production hosting.
* **Modern Web Standards:** Semantic HTML5, accessible touch targets, dynamic content loading, and progressive image rendering (`.webp`).

---

## 🛠 Tech Stack

* **Frontend:** React.js, Tailwind CSS, Framer Motion
* **Design & Prototyping:** Figma
* **Hosting & DNS:** DreamHost, Cloudflare DNS
* **CI/CD:** GitHub Actions
